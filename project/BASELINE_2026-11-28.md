## 1. Exact product and package contract (CODE + LIVE registry)

- **Architecture:** small, open-source MIT **two-language TOTP library monorepo**. Node.js CommonJS entry `javascript/src/kron-otp.js`; PyPI single module `python/src/kron_otp.py`; **stateless synchronous local** OTP generation and verification. No network API, server middleware, CLI, account provisioning, built-in rate limiting, or code-replay store.
- **Node distribution:** npm `kron-otp@2.0.0`, Node `>=20.19.0`, runtime `otpauth ^9.6.0` (lock resolves 9.6.0 + `@noble/hashes 2.4.0`). CommonJS export is `KronOTP` class both direct `require('kron-otp')` and named `require('kron-otp').KronOTP` alias. `generate(secret)` and `verify(secret, token)` are the **only two public static methods**.
- **Python distribution:** PyPI `kron-otp==2.0.0`, Python `>=3.10`, `pyotp>=2.12,<3` (not fully lock-pinned). Import `from kron_otp import KronOTP`, public static `generate(secret: str)->str` and `verify(secret: str,token: str)->bool`. The Python package is **not** the Tkinter app.
- **Shared behavior:** HMAC-SHA1, exactly 6 ASCII decimal digits as a **string**, 30-second period; stateless verify tolerates previous/current/next step (±1). Already provisioned canonical Base32 with only ASCII whitespace normalization; **≥14 decoded bytes accepted** (recommend **20+ random bytes**), ≤4096 raw / ≤1024 normalized characters; checks canonical unused padding bits.
- **Error contracts:** Node invalid generate secret → `TypeError`, Python → `ValueError`; ordinary malformed token/secret for verify → false/False. Python special-case avoids a negative counter during Unix epoch seconds 0–29. There is **no configurable hash/digits/period/timestamp/window** public parameter. Server enrollment, replay prevention, rate limiting, session handling and clock hygiene belong to integrators.
- **Published registry reality (LIVE 2026-11-28):** npm `kron-otp/latest` reports `2.0.0`, with `gitHead` pointing to `eefafd...`; PyPI latest `info.version` is `2.0.0`, wheel `kron_otp-2.0.0-py3-none-any.whl` and sdist `kron_otp-2.0.0.tar.gz` are present; no new release was created in this audit.
